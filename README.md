# GOBBLET — ゴブレット

4×4 の盤で遊ぶ抽象戦略ゲーム「ゴブレット」の Web 版です。大きい駒で小さい駒を覆いながら、縦・横・斜めのいずれかに自分の駒を 4 つ並べると勝ちです。

- 公開 URL: https://a-kaibu.github.io/gobblet/
- リポジトリ: https://github.com/a-kaibu/gobblet

## 遊び方

- 手持ちの駒を 1 つ選び、空きマスか、自分より小さい駒の上に置きます。
- 盤上の自分の駒を移動できます。動かせるのは上に何も乗っていない駒だけです。
- 大きい駒は小さい駒を覆います。覆われた駒は動かせません。
- 相手の 4 連を露出させてしまうと、その時点で相手の勝ちです。
- 同じ局面が 3 回現れるか、200 手に達すると引き分けです。
- 打てる手がない場合は、その時点で相手の勝ちです。

## 機能

- CPU 対戦（よわい / ふつう / つよい）とローカル 2 人対戦
- 駒のスタック表示、移動先のハイライト、ゴーストプレビュー
- 待った、棋譜表示、勝敗の演出、効果音（オン / オフ切り替え可能）
- キーボード操作（矢印キーで盤面を移動、Enter / Space で選択）
- レスポンシブ対応（スマートフォンでは盤面の下に手持ちを表示）

## 開発

```bash
pnpm install
pnpm dev
```

Vite+ の `vp` コマンドを使用しています。

```bash
pnpm build    # 型チェック + 本番ビルド
pnpm test     # ゲームエンジンと AI のテスト
pnpm lint     # Oxlint
```

## 構成

- `src/game/` — ルールエンジン、合法手生成、棋譜、CPU AI
- `src/components/` — 盤面、手持ち、ステータス、ダイアログなどの UI
- `src/pages/` — 対局ページ
- `src/index.css` / `src/game.css` — デザイントークンとゲーム画面のスタイル
- `.github/workflows/deploy.yml` — GitHub Pages への自動デプロイ

`main` ブランチへ push すると GitHub Actions がビルドし、GitHub Pages へデプロイします。
